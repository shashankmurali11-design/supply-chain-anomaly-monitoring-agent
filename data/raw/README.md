# Sample shipment table

`supplier_deliveries.csv` is fictional practice data: 27 inbound shipments from three suppliers. It includes ordinary deliveries and a few deliberately unusual rows (late arrivals, a short receipt, a very large order, and a high unit cost) for later lessons.

Each row is one shipment. `quantity_ordered` and `quantity_received` use the unit shown in `unit`. `cost_per_unit` is in EUR. The examples are invented and are not real supplier issues.
